## Changes
- functions.php loads inc/seo.php after the existing modules.
- Remove the global assistant index from rendered HTML. The helper searches WordPress's built-in public search API only after a guide query, returns source links, limits responses to 12 and uses a bounded in-memory cache. No external AI service or saved chat transcript.
- assets/js/assistant-seo-20261019.js is a distinct filename because the live optimizer stripped asset version query strings and the browser retained an older script. Keep the legacy assistant.js unchanged.
- No 400-post search cutoff: native WordPress search queries all matching public posts. Existing rbh_assistant_index is dormant for backward compatibility.
- Hero and eager single featured images carry data-no-lazy=1, loading=eager and fetchpriority=high. Other images retain their existing lazy behavior.
- Nine existing category slugs have individually edited descriptions and introductory guidance. Yoast filters keep category head/OG/schema descriptions aligned; no database taxonomy rewrite.
- Category hubs include starter links, existing child navigation and existing pagination.
- Yoast breadcrumbs choose an assigned primary category, otherwise the deepest assigned category, and include real ancestors. Both rendered HTML and JSON-LD reuse Yoast's chain.
- Related guides rank a maximum pool of 60 public candidates by informative title-word overlap and shared tags. Same-category recency is a fallback, not a guarantee of semantic relevance.
- Contact OG description is improved; Honda Wave informative homepage image receives descriptive alt if missing.
- No homepage title, description, OG identity, site name, canonical or business identity is modified.
